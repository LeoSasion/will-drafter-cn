# 民法典继承编关键条文索引（中国大陆）

效力顺位总原则：遗赠扶养协议 > 遗嘱 > 法定继承（1123）。

## 条文速查表

| 条号 | 主题 | 要点 |
|---|---|---|
| 1121 | 继承开始 | 从被继承人死亡时开始；同一事件中难以确定死亡时间的推定规则 |
| 1122 | 遗产定义 | 自然人死亡时遗留的**个人合法财产** |
| 1123 | 效力顺位 | 有遗赠扶养协议的按协议；有遗嘱的按遗嘱；都没有的按法定 |
| 1124 | 接受与放弃 | 继承：不表示视为接受；受遗赠：知道后 60 日内须明示接受，逾期视为放弃 |
| 1125 | 丧失继承权 | 故意杀害被继承人、为争遗产杀害其他继承人、遗弃/虐待情节严重、伪造篡改隐匿销毁遗嘱情节严重、欺诈胁迫立遗嘱情节严重；第三至五类有宽恕恢复制度 |
| 1127 | 法定继承顺序 | 第一顺序：配偶、子女、父母；第二顺序：兄弟姐妹、祖父母、外祖父母。子女含婚生、非婚生、养子女、有扶养关系的继子女 |
| 1128 | 代位继承 | 子女先于被继承人死亡的，由其直系晚辈血亲代位；兄弟姐妹先死亡的，其子女可代位 |
| 1129 | 丧偶儿媳/女婿 | 对公婆/岳父母尽了主要赡养义务的，作为第一顺序继承人 |
| 1130 | 份额原则 | 同一顺序一般均等；生活特殊困难又缺乏劳动能力的予以照顾；尽主要扶养义务或共同生活的可多分；有扶养能力不尽义务的不分或少分 |
| 1131 | 酌情分得 | 继承人以外依靠被继承人扶养的人，或对其扶养较多的人，可适当分得遗产 |
| 1133 | 遗嘱处分 | 可指定遗嘱执行人；可遗赠给国家、集体或法定继承人以外的组织、个人；可依法设立遗嘱信托 |
| 1134–1139 | 六种形式 | 自书、代书、打印、录音录像、口头、公证（要件详见 forms-and-invalidity.md） |
| 1140 | 见证人资格 | 三类人员不得见证（详见 forms-and-invalidity.md） |
| 1141 | 必留份 | **必须**为缺乏劳动能力又没有生活来源的继承人保留必要份额 |
| 1142 | 撤回与顺位 | 可撤回、变更自己所立遗嘱；数份抵触以最后为准；公证遗嘱不再优先 |
| 1143 | 实质要件 | 无/限制行为能力人所立无效；受欺诈、胁迫无效；伪造无效；篡改的内容无效 |
| 1144 | 附义务遗嘱 | 继承人/受遗赠人应履行义务；无正当理由不履行的可被取消接受权 |
| 1145–1149 | 遗产管理人 | 选任（遗嘱执行人为当然管理人）、争议时法院指定、职责（清点清单、报告、防损、清偿、分割）、过错赔偿责任、报酬 |
| 1153 | 夫妻共同财产 | 分割时先将共同财产的一半分出为配偶所有，其余为遗产 |
| 1154 | 法定继承适用 | 遗嘱未处分的遗产、放弃/丧失/先亡/无效部分，回到法定继承 |
| 1155 | 胎儿预留份 | 分割时应保留胎儿份额；娩出为死体的按法定继承处理 |
| 1156 | 分割原则 | 有利生产生活需要，不损遗产效用；不宜分割的可折价、适当补偿或共有 |
| 1157 | 再婚处分权 | 配偶再婚的有权处分所继承财产，任何人不得干涉 |
| 1158 | 遗赠扶养协议 | 与继承人以外的组织或个人签订；承担生养死葬义务，享有受遗赠权利 |
| 1159 | 清偿义务 | 分割前清偿税款债务；同时保留必留份 |
| 1161 | 限定继承 | 以所得遗产实际价值为限清偿税款债务；自愿偿还不限；放弃继承的可免责 |
| 1162 | 清偿优先 | 执行遗赠不得妨碍清偿税款债务 |
| 1163 | 混合清偿 | 既有法定又有遗嘱继承的：法定继承人先清偿；超出部分由遗嘱继承人和受遗赠人按比例分担 |

## 债务与税款清偿顺序

1. 先清偿税款和债务，再分割遗产、执行遗赠（1159、1162）
2. 限定继承：继承人只以所得遗产实际价值为限担责（1161）
3. 混合情形：法定继承人先清偿 → 超出部分由遗嘱继承人和受遗赠人按所得比例分担（1163）
4. 分割时仍须保留必留份（1159 后段）

## 遗产税口径

中国大陆目前未开征遗产税。按现行官方口径如实说明。不预测立法动向，不把境外遗产税制套用到境内底稿。

## 涉外与跨域提示

立遗嘱人身份、住所或财产涉及中国港澳台地区或外国的，继承关系可能适用《涉外民事关系法律适用法》的冲突法规则（如不动产适用物之所在地法）。此类情形必须建议委托涉外家事专业律师，本技能底稿仅作意愿整理参考。

## 虚拟财产与新型资产

- 自媒体账号、游戏账户等网络虚拟财产：民法典 127 条承认其财产属性受保护，但平台用户协议常限制流转，可处分性因平台而异——在底稿中标注「以平台规则为准，建议同时留下账号信息指引」
- 加密资产：可处分，但强调凭证（助记词/私钥）保管与交接安排，只记存放位置不记密钥内容
- 保险：指定了受益人的保险金归受益人不进遗产；未指定的按遗产处理
