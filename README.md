# will-drafter-cn

**中国大陆法域的 AI 遗嘱起草技能（Agent Skill）。** 把"想立遗嘱"整理成一份要素齐全的遗嘱底稿 + 全套落地指引。

## 为什么需要它

大量遗嘱因为**形式瑕疵**被法院认定无效：末尾没签名只写"我叫某某"、盖名章代替亲笔签名、写"我今年九十三岁"没注明年月日、打印遗嘱漏签某一页、见证人是继承人的利害关系人……每一个都是真实判例里的无效理由。

本技能不替你"写遗书"，而是用结构化流程把意愿、事实、法律要件全部梳理清楚，产出可核对的底稿与签署清单——**形式要件必须由本人完成**。

## 方法论来源

以 [Rohas Legal AI](https://github.com/rohasnagpal/legal-ai-skills) 的 **will-drafter** 技能（MIT License）的方法论为骨架，法域内容整体替换为《中华人民共和国民法典》继承编（第 1119–1163 条）。

核心方法论——**四条独立的有效性风险线**，逐条单独评估，任何一条不通过即足以导致遗嘱无效或部分无效：

| 风险线 | 判定问题 | 民法典依据 |
|---|---|---|
| 行为能力 | 立遗嘱时是否具有完全民事行为能力 | 1143 |
| 真实意思 | 是否自愿作出，无欺诈、胁迫、伪造、篡改 | 1143 |
| 财产权属 | 所处分的确属立遗嘱人个人合法财产 | 1122 / 1153 / 1155 |
| 形式要件 | 是否满足所选遗嘱形式的全部法定要件 | 1134–1140 |

## 功能

- **十步起草法**：固定准据法 → 评估行为能力与真实意思 → 梳理权属（夫妻共同财产先析产）→ 设计处分方案 → 保护必留份与胎儿份额 → 指定遗嘱执行人 → 分配债务税款 → 撤销与解释条款 → 形式落地 → 保管复核计划
- **七件套输出**：遗嘱底稿、指示与假设备忘录、资产→条款映射表、有效性风险说明、形式落地清单、保管复核计划、家属交接包
- **六种形式要件对照**：自书 / 代书 / 打印 / 录音录像 / 口头 / 公证（1134–1139），含法院列举的常见无效点
- **中国特有规则内置**：必留份不可规避（1141）、受遗赠 60 日接受时限（1124）、公证遗嘱不再优先（1142）、见证人资格排除（1140）、限定继承清偿顺位（1159–1163）
- **虚拟财产处理**：自媒体账号、游戏账户、加密资产的处分性与交接指引

## 安装

任何支持 SKILL.md 约定的 Agent 运行时（WorkBuddy、Claude Code 等）均可使用——把本仓库放进对应的 skills 目录即可：

```bash
# WorkBuddy（用户级，跨项目可用）
git clone git@github.com:LeoSasion/will-drafter-cn.git ~/.workbuddy/skills/will-drafter-cn

# Claude Code
git clone git@github.com:LeoSasion/will-drafter-cn.git ~/.claude/skills/will-drafter-cn
```

克隆后说一句"帮我立遗嘱"或"打印遗嘱需要什么条件才有效"即可触发。

## 重要免责声明

- 本技能产出的是**遗嘱底稿与操作指引，不具法律效力**
- 录音录像遗嘱必须本人亲自出镜出声、一镜到底无剪辑，**AI 生成的一律无效**（中国法院网 2026 年口径）
- 遗嘱有效性取决于真实意思与法定形式要件，二者均须由本人完成
- 执行前建议经执业律师或公证处复核；涉诉讼、股权、跨境财产的必须委托专业律师
- 法条内容整理自《中华人民共和国民法典》继承编及中国法院网（2026）、北京市第一中级人民法院（2024）普法材料，以现行有效法律文本为准
